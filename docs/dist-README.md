# Ghost for Discord (built)

This is the built [Ghost](https://github.com/RazerGhost/discord-ghost) Discord theme
and Vencord plugin, published automatically from `main`. Source, issues and docs live
on the [main branch](https://github.com/RazerGhost/discord-ghost).

| File | What it is |
| --- | --- |
| `ghost.theme.css` | The theme (Vencord, Equicord, BetterDiscord) |
| `ghost-oled.theme.css` | The same, with pure black panels |
| `ghost/` | The Vencord userplugin — copy this folder into Vencord's `src/userplugins/` |

Online Themes URL (Vencord / Equicord → Settings → Themes → Online Themes):

```
https://raw.githubusercontent.com/RazerGhost/discord-ghost/dist/ghost.theme.css
```
